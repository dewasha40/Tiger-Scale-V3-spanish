# v3.4.0

La pantalla de actualización ahora muestra la versión instalada, destaca la nueva versión disponible y responde antes de pulsar **Instalar** a la pregunta importante: sí, se conservan el Wi-Fi, la cuenta y la calibración. Además, la propia lista de Ajustes indica cuando hay una actualización pendiente.

## Cambiado

- **La pantalla de actualización se reconstruyó por completo.** La versión instalada aparece en una fila clara; una nueva versión se muestra en un aviso ámbar de «Nueva versión», con un botón azul **Instalar** de tamaño completo y, justo debajo, el mensaje importante: *Se conservan el Wi-Fi, la cuenta y la calibración*. Si está actualizado, aparece una marca verde con un texto claro. Si falla la comprobación, se muestra una etiqueta roja con el botón **Reintentar**, en lugar de un mensaje de error inerte. El anillo de progreso de instalación —porcentaje y aviso «No apagues el dispositivo»— no cambia.
- **Ajustes avisa cuando hay una actualización pendiente.** Cuando la comprobación en segundo plano encuentra una versión nueva, el icono de la fila **Actualización** se vuelve naranja y el valor muestra el cambio —«3.3.1 > 3.4.0»—, para que recibas el aviso sin abrir esa pantalla.

## Problemas conocidos

- Las lecturas de metadatos de una etiqueta todavía recurren a los valores en caché; una bobina que nunca se haya leído podría no mostrar marca ni material.

## Actualización

- **Por el aire**, desde **Ajustes > Actualización**: conserva las credenciales Wi-Fi, la sesión de TigerTag y la calibración.
- **Por USB**, con `bash scripts/flash.sh --fs`: ofrece la misma garantía.
- **Desde el navegador**, mediante el [instalador web](https://tigertag-project.github.io/Tiger-Scale-V3/): instala siempre la versión más reciente, pero como una **instalación limpia**. Restablece la báscula a los valores de fábrica y el asistente de primer inicio vuelve a pedir idioma, Wi-Fi, cuenta y calibración.
