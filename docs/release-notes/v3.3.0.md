# v3.3.0

Si la báscula todavía no tiene una cuenta vinculada, ahora ofrece conectarla directamente: poco después del arranque aparece un panel sobre la pantalla de inicio con el mensaje «Conecta tu cuenta» y un botón azul **Iniciar sesión**, en vez de esperar a que encuentres esa opción en Ajustes.

## Añadido

- **La báscula invita a vincular una cuenta.** Si no hay una cuenta vinculada y el Wi-Fi está conectado, poco después del arranque aparece un panel lateral sobre la pantalla de inicio: «Conecta tu cuenta», con un botón azul **Iniciar sesión** que abre las opciones habituales (correo electrónico o código QR para Google). Al elegir **Más tarde**, el panel se cierra; solo volverá a aparecer cada media hora y nunca durante un pesaje. La vinculación sigue siendo opcional: la báscula continúa funcionando sin conexión como antes.

## Problemas conocidos

- Las lecturas de metadatos de una etiqueta todavía recurren a los valores en caché; una bobina que nunca se haya leído podría no mostrar marca ni material.

## Actualización

- **Por el aire**, desde **Ajustes > Actualización**: conserva las credenciales Wi-Fi, la sesión de TigerTag y la calibración.
- **Por USB**, con `bash scripts/flash.sh --fs`: ofrece la misma garantía.
- **Desde el navegador**, mediante el [instalador web](https://tigertag-project.github.io/Tiger-Scale-V3/): instala siempre la versión más reciente, pero como una **instalación limpia**. Restablece la báscula a los valores de fábrica y el asistente inicial volverá a pedir idioma, Wi-Fi, cuenta y calibración.
