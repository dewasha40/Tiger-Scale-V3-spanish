# v3.7.0

En gran medida, esta versión no cambia lo que ocurre en la propia báscula: se centra en las aplicaciones que se comunican con ella. Tiger Studio Manager por fin puede leer las respuestas que solicita a la báscula y una sola petición devuelve toda la información.

## Corregido

- **Las aplicaciones no podían leer las respuestas de la báscula.** Una aplicación web —incluido Tiger Studio Manager— podía enviar un comando y hacer que la báscula lo ejecutara, pero no recibía la respuesta. Su botón de tara indicaba que había funcionado tanto si la báscula había tarado como si estaba desenchufada. Ahora la báscula responde correctamente.
- **Dos endpoints de diagnóstico nunca habían funcionado.** `/api/session` y `/api/history` devolvían «not found» en todas las unidades distribuidas. Ahora muestran el pesaje en curso y un breve registro de eventos.

## Añadido

- **Una petición devuelve toda la información de estado.** `/api/status` ahora incluye el nivel de batería, si hay batería instalada, si está cargando, si la báscula funciona por USB o batería, el estado de la pantalla y la señal Wi-Fi: los mismos valores que la aplicación ya recibe en directo. Si pierde la conexión en directo, una aplicación puede volver a sincronizar el estado en una sola llamada.

## Cambiado

- La báscula sigue rechazando desde las páginas web los comandos que cambian su configuración: calibración, cuenta y actualizaciones. Consultar el estado y hacer una tara están permitidos; cambiar la configuración del dispositivo, no. La API local no tiene contraseña, y esta restricción es lo que la protege.

## Problemas conocidos

- Las lecturas de metadatos de una etiqueta todavía recurren a los valores en caché; una bobina que nunca se haya leído podría no mostrar marca ni material.

## Actualización

- **Por el aire**, desde **Ajustes > Actualización**: conserva las credenciales Wi-Fi, la sesión de TigerTag y la calibración.
- O desde el [instalador web](https://tigertag-project.github.io/Tiger-Scale-V3/), que siempre ofrece la versión actual.
