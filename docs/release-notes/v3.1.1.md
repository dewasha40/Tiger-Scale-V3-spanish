# v3.1.1

Tareas de mantenimiento en los elementos externos de la báscula: se reconstruyó la página del instalador y el enlace de la interfaz web del dispositivo ahora lleva al ecosistema en vez de a la tienda.

## Corregido

- El enlace del pie de página de la interfaz web apuntaba a la tienda de TigerTag. Ahora lleva a tigersystem.io, donde se describe el ecosistema. Se aplicó la misma corrección al README y a la página del instalador.

## Cambiado

- Se reconstruyó el instalador web para quienes nunca han programado una placa: ahora explica qué preparar, incluye una pregunta sobre el cableado con un diagrama interactivo, una lista de compra e instrucciones más claras.
- Está disponible en **nueve idiomas**, los mismos que la interfaz web de la báscula. Se elige el idioma desde un menú y, en la primera visita, se detecta automáticamente el idioma del navegador.
- Incluye modo claro y oscuro; el modo oscuro es el predeterminado y se puede cambiar con un interruptor.

El firmware no cambia respecto a v3.1.0. Aun así, merece la pena actualizar si usas la interfaz web de la báscula, porque la imagen del sistema de archivos incluye la corrección del enlace.

## Actualización

Actualiza por el aire desde **Ajustes > Actualización**, o por USB con `bash scripts/flash.sh --fs`. Ambos métodos conservan las credenciales Wi-Fi, la sesión de TigerTag y la calibración.
