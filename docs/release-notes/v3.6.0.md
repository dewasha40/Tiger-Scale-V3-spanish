# v3.6.0

Corrige una lectura de batería que podía mostrar un valor incorrecto y añade el botón Reiniciar que necesita una báscula con batería instalada.

## Corregido

- **El nivel de batería podía mostrar solo parte de sus cifras.** Entre aproximadamente el 50 % y el 80 %, desaparecía la segunda cifra: una báscula al 55 % mostraba «5». La cifra estaba dibujada en un color oscuro que coincidía con la parte oscura del icono. Ahora el porcentaje siempre se puede leer, sea cual sea el nivel.

## Añadido

- **Ajustes incluye un botón Reiniciar**, justo encima de Restablecer valores de fábrica. Con la batería instalada no había forma de reiniciar manualmente la báscula: desconectar el USB ya no la apagaba, porque seguía funcionando con batería. El botón pide confirmación y conserva todos los datos: Wi-Fi, cuenta y calibración.

## Cambiado

- **Cuando funciona con batería, la barra de nivel es azul**; permanece verde mientras carga y se vuelve roja cuando el nivel es bajo. La barra blanca anterior hacía que desapareciera la cifra, así que hubo que cambiar el color para que la lectura fuese fiable.

## Problemas conocidos

- Las lecturas de metadatos de una etiqueta todavía recurren a los valores en caché; una bobina que nunca se haya leído podría no mostrar marca ni material.

## Actualización

- **Por el aire**, desde **Ajustes > Actualización**: conserva las credenciales Wi-Fi, la sesión de TigerTag y la calibración.
- O desde el [instalador web](https://tigertag-project.github.io/Tiger-Scale-V3/), que siempre ofrece la versión actual.
