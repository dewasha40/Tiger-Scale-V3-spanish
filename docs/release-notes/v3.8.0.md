# v3.8.0

Ahora se puede apagar la báscula.

## Añadido

- **Opción para apagar en Ajustes.** Esta placa no tiene botón de encendido, así que una báscula funcionando con batería no tenía forma de apagarse: al desconectar el USB pasaba a alimentarse de la batería en lugar de detenerse. La nueva opción aparece debajo de **Reiniciar** y, al confirmar, indica cómo volver a encenderla: conecta el cable USB. Se conservan el Wi-Fi, la cuenta y la calibración, como en cualquier otro reinicio del dispositivo.

  Si el cable está conectado, la fila explica que no puede ejecutar la acción: con USB conectado, las líneas de alimentación se apagarían y volverían inmediatamente, lo que parecería un reinicio inexplicable. Desconecta el cable y la fila pasa a color ámbar y se activa.

## Cambiado

- **La lista de Ajustes responde al estado del cable.** Si conectas o desconectas el USB mientras la lista está abierta, ahora se actualiza en el mismo sitio y conserva la posición de desplazamiento, en vez de mostrar el estado que había al abrir la pantalla.
- **Las filas de Ajustes que no abren otra pantalla ya no muestran una flecha.** La flecha indica que la fila conduce a otro lugar.
